これは日本語の demo 記事です。ブログの本文が日本語でも読みやすく表示されるかを確認するために、**太字**、*斜体*、`インラインコード`、リンク、リスト、引用、表、コードブロックを入れています。

文章の内容はシンプルですが、実際の記事に近い密度になるように構成しています。

## 概要

この記事では、次のような要素を確認できます。

- 見出しと本文の余白
- 箇条書きと番号付きリスト
- チェックリスト、引用、水平線
- 表、コードブロック、脚注
- 日本語タグと英数字の混在

## 書くときの流れ

技術メモを書くときは、次の順番にすると読みやすくなります。

1. 問題や背景を短く説明する。
2. 試したことを具体的に並べる。
3. 結果と次のアクションを書く。

### 確認リスト

- [x] 日本語のタイトルが折り返される
- [x] 英数字と日本語が同じ段落で表示される
- [x] コードブロックの横幅が保たれる
- [ ] 画像を追加した場合の余白も確認する

> デモ記事の役割は、実際の記事を書く前に表示上の違和感を見つけることです。

## サンプル表

| 項目 | 内容 | 確認ポイント |
| --- | --- | --- |
| Frontmatter | 記事のメタ情報 | 日付、タグ、概要が表示されるか |
| 本文 | Markdown の主要コンテンツ | 行間と余白が自然か |
| コード | 実装例やコマンド | 背景色と可読性 |

## コード例

```ts
const labels = {
  zh: '中文',
  en: 'English',
  ja: '日本語',
};

function getLabel(locale: keyof typeof labels) {
  return labels[locale];
}
```

短いコマンドは `npm run dev` のように本文中にも書けます。
