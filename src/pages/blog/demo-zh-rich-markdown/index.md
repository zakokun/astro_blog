这是一篇中文 demo 文章，用来检查博客正文在不同内容密度下的表现。正文里会混合使用**加粗文本**、*斜体文本*、`行内代码`、链接、列表和代码块。

你可以把它当作一个内容样板：如果未来要写技术笔记、读书摘录、产品复盘或旅行记录，可以直接参考这里的结构。

## 文章摘要

下面是这篇文章覆盖的主要元素：

- 多级标题和普通段落
- 无序列表、有序列表和任务清单
- 引用块、分隔线和脚注
- 表格、代码块和行内代码
- 链接、强调文本和简短结论

## 一段带层次的内容

写博客时，结构通常比字数更重要。一个可读性不错的技术笔记，往往会包含三个层次：

1. 背景：为什么要写这件事。
2. 过程：尝试了哪些方案，遇到了什么问题。
3. 结论：最终选择是什么，还有哪些后续工作。

### 观察清单

- [x] 标题层级清晰
- [x] 段落之间有足够间距
- [x] 代码块可以横向滚动
- [ ] 表格在移动端也需要重点检查

> 好的 demo 文章不需要表达复杂观点，但应该尽量覆盖真实写作中会出现的内容形态。

## 示例表格

| 模块 | 用途 | 检查点 |
| --- | --- | --- |
| Frontmatter | 提供标题、日期、摘要和标签 | 博客列表是否正确读取 |
| Markdown 正文 | 承载主要内容 | 标题、列表、代码块是否排版正常 |
| 标签筛选 | 按主题过滤文章 | 中文标签是否能正常点击 |

## 示例代码

下面是一段 TypeScript 风格的示例代码：

```ts
type Post = {
  title: string;
  date: string;
  tags: string[];
};

function summarize(post: Post) {
  return `${post.title} (${post.tags.join(', ')})`;
}
```

也可以在段落里写短命令，例如运行 `npm run build` 来检查项目是否能成功构建。
