小学和初中时，我经常当班长、课代表。学校开运动会，我也要写一些交给广播站的短稿。具体文字已经记不清，大概是这样的：

> X 年 X 班代表队迈着整齐的步伐向我们走来。他们雄赳赳、气昂昂，他们精神饱满，他们眼神坚定，充分展现了 X 年 X 班团结进取、奋勇拼搏的精神风貌。

没有老师发给我们模板，这些稿子都是学生自己写的。奇怪的是，最后写出来都差不多。换掉班级和运动项目，同样的句子可以继续使用。

广播站会公开朗读这些稿子。能够被念出来，本身便暗示了这是一种好的、正式的中文。当时我也这样认为。很多年以后再回头看，我相信学生并没有凭空发明这种文体。我们每天从《新闻联播》、报纸和学校活动里听到类似的声音，需要把话说得“高级”时，便自然地模仿了它。

这种模仿甚至不需要老师指导。公共语言已经替我们准备好了格式。

## 苹果为什么写不好中文

苹果的简体中文文案经常引起讨论。2018 年，它在微信公众号的发布会预告里用了“你懂的”和“官宣”。2020 年的 iPhone SE 页面又出现了“人像模式走起，笑一个”和“给主屏幕按钮点赞”。这些句子放在苹果的网站上，总有一种说不出的古怪。[《中港台 iPhone SE (2020) 文案对比》](https://blog.yitianshijie.net/2020/04/16/2020-iphone-se-copy-3-chinese-versions-vs-english/)

通常的解释是翻译水平不够，或者苹果不了解中国。但译者真正面对的问题可能更大：苹果应该用什么样的中文说话？

太正式，很容易写成公文或者翻译腔；想显得亲切，又会立即滑向“走起”“点赞”“官宣”这些网络用语。中间那一大片自然、现代、体面的表达，似乎很难找到。

李如一在《一天世界》中把它称为“语言工具箱”的问题。他认为苹果中文的别扭最终来自中文使用者自己。一个外国公司来到中国，只能从这里已经存在的公共语言中挑选工具。工具箱里有什么，它就会写出什么。[《苹果中文的新（jiù）问题》](https://blog.yitianshijie.net/2018/10/19/the-new-old-problem-of-apple-china-copywriting/)

苹果文案和学校运动会的广播稿看上去相距很远，处境却很接近。一旦要离开日常口语，写作者很快就会遇到两种现成选择：像宣传稿一样庄重，或者像社交媒体一样活泼。

## 共产中文

《一天世界》还使用过一个更直接的说法：“共产中文”。这个词带有明确的贬义，指向一套由政治、教育和宣传环境塑造的语言。它和简体字没有必然关系，也不能用来概括所有中国人写下的文字；在繁体中文环境中，同样可能出现这种语体。[《“简中”的问题》](https://blog.yitianshijie.net/2024/02/15/on-the-neologism-known-as-jianzhong/)

这里所说的“共产中文”，可以从它处理事实的方式来辨认。

它喜欢使用集体作为主语，依靠排比制造气势，再用“积极”“坚定”“圆满”“全面”之类的词预先确定感情。句子里经常有宏大的行动，却很少交代具体是谁做了什么、遇到什么困难、最后产生什么结果。

运动会广播稿就是一个很小的样本。真实的队伍未必步伐整齐，每个人的状态也不相同。但进入那套格式以后，所有代表队都精神饱满，所有脚步都整齐有力，所有人都朝着同一个目标前进。

一篇几十字的广播稿容不下运动员的全部状态。问题在于，我们把这套句子当成了“高级中文”。学生自己写，学校公开播放，下一届学生继续学习。没有人正式规定，格式仍然一代一代保存下来。

## 当高级中文只有一种

这种语言很适合完成仪式，统一情绪，表明立场。它的影响扩大以后，人们在其他场合也会沿用同样的办法。

进入互联网公司，它换了一批词。宣传稿里的“积极推进”和“全面落实”，到了公司里变成“协同”“赋能”“生态”和“闭环”。词汇看起来很新，句子的任务没有太大变化：让一件事显得正确、重要、正在顺利发生。

“这个产品赋能了行业”听起来很完整，却没有告诉人们它降低了多少成本、改变了哪个流程，或者只是卖出了一套软件。“公司持续优化人才结构”也不会主动说明有多少人失去工作，谁作出了决定，代价又由谁承担。

这套习惯还会改变概念的边界。

“封建”原本用于描述历史和政治制度。在中国传统语境里，它指封土建国、封爵建藩，与郡县相对；近代以后又被用于翻译 feudalism，随后进入社会发展阶段的叙述。[冯天瑜对“封建”概念的考察](https://www.cssn.cn/dfpd/djyx/202506/t20250619_5881969.shtml)

今天说一个人“封建”，可以指父权、专制、迷信、保守，也可以只表示说话的人不喜欢某种旧习惯。这个词已经完成了批评，至于眼前的现象究竟来自家庭结构、权力关系还是具体利益，往往不必再说。

语言仍然能够表达赞美和谴责，描述现实的部分却越来越薄。

## 工具箱

这里所说的中文劣化，首先表现为可供选择的语体和词语越来越少。日常说话可以很自然，一旦进入正式场合，许多人便不自觉地切换到新闻、会议和宣传活动中的腔调。想躲开这种腔调，又很容易只剩下网络流行语。

好的公共中文需要在公共生活中反复出现。香港巴士上的公益广告把 “Be a volunteer” 写成“齐来行义”；旧日的政府译稿、商业广告和机构文案，也保留过各自的分寸和语气。这些文字未必句句完美，它们至少让人看到，正式中文还可以有别的样子。[《我嘅师承》](https://blog.yitianshijie.net/2024/05/19/ngo-ge-si-sing/)

如果一个人从小听到的正式中文只有一种，他长大后很难突然写出另一种。苹果雇到再优秀的译者，也无法完全脱离它身处的语言环境。

一个社会当然可以不断创造新词。真正需要担心的是，当我们想认真描述一件事时，拿出来的仍然只有那些早已替我们决定了语气、态度和结论的句子。
